01What Is The MATLAB / Simulink MCP?

MCP — Model Context Protocol. An open standard that gives an AI agent hands: instead of only writing text, it can call real tools. MathWorks ships an official MCP server for MATLAB and Simulink.

The brain AI agent GitHub Copilot, Claude Code — any MCP-capable client. Interchangeable.

03Simulink MCP — Skills & Capabilities
Tools — what the agent can do
  • Read & navigate model hierarchies, blocks, parameters
  • Build & edit models — blocks, connections, configuration
  • Run simulations and read back the results
  • Run model checks & tests — structure, coverage, assertions
  • Execute MATLAB code — scripts, analysis, plotting
Skills — the expertise it follows
  • Building Simulink models — MathWorks best practices
  • Simulating & debugging — diagnosing model issues
  • Testing & verification — test authoring, harnesses, checks
  • Specifying MBD algorithms — requirements → structure
  • Managing Simulink projects — layout, dependencies
Shipped skills are generic. Schaeffler skills on top — standards, templates, checklists — that layer is the harness.

05Limits & Next Steps
Honest limits
