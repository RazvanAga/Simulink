## 5. Protection subset

**Modeled** (limits from §3):
- Motor overspeed: ω_m ≥ 16,000 rpm → torque cut to 0 (latched) + flag + sim stop
- Torque limiting: T ≤ 255 Nm at all times (saturation, not a fault)
- Power limiting: P_mech ≤ 155 kW (saturation via P/ω characteristic)
- DC overcurrent check: I_dc > 550 A → flag (should never assert — see AC6)

**Explicitly OUT OF SCOPE** (per config): thermal derating (continuous vs 10 s rating),
regenerative braking, road loads, efficiency maps, FOC/PWM behavior, NVH, EMC,
parking brake, torque vectoring, aging.

## 6. Simulation scenario

- Maneuver: full-throttle launch — torque request step **300 Nm** at t = 0

## 9. Open items (engineer must rule on these)

1. **Base variant power/torque discrepancy** — VMS Fig. 2 (155 kW / 2,750 Nm) vs body
   text (135/165 kW, 2,500/3,000 Nm). Spec uses Fig. 2 platform values with the 3,000 Nm
   reducer family bound. Engineer to confirm or switch to the 165 kW text value.
2. **`i_gear` = 11.64 is a selection**, not a documented Base value — only the range
   9.3–11.64 is documented. Consistency argument given in §3; a different ratio shifts
   top speed (i = 9.3 → 227 km/h) and axle torque (→ 2,300 Nm, below Base figure).
3. **Efficiencies are ASSUMED** (η_red = 0.97, η_em_inv = 0.94). The paper proves
   efficiency *improvements* (Figs. 4–5, −19…−53 % losses) but gives no absolute map.
   AC3/AC6 margins absorb ±2 % error; production use needs supplier map data.
4. **Vehicle mass and wheel radius ASSUMED** (2,300 kg within documented class range;
   0.35 m typical). These scale AC4/AC5 directly — engineer may pin them to a target
   vehicle.
5. **255 Nm reducer input limit** is stated for the reducer family "regardless of the
   design" (VMS p. 9), yet the Enhanced 4,000 Nm variant implies ~354 Nm input. We read
   255 Nm as the **Base** family limit; flagged because the paper's wording is ambiguous.
6. **Document vintage**: VMS is 2021 development status; the 2025 Vitesco product page
   (not in `1_raw_data/`, capture failed) lists 100–250 kW — the platform has evolved.
   This spec models the 2021-documented platform, independently confirmed by SHF (2025)
   at 80–230 kW.
7. **No measured curves** → §8 validation is structural/envelope-based, weaker than the
   measured-curve validation used in `molicel_48v_pack`. Declared, not hidden.
