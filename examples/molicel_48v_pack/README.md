# molicel_48v_pack — 48 V Pack (13s4p) from Molicel INR-21700-P45B

Demo candidate A: a pack-level 2nd-order Thevenin ECM generated by an AI agent from
**real supplier documents**, through a harness pipeline with a human validation gate.

## Pipeline (folders = stages, in order)

```
1_raw_data/   →   2_prompts/                →   3_spec/      →   4_model/        →   5_docs/
raw PDFs          extraction + generation       spec.md          .slx + params       architecture doc
(supplier)        prompts (harness skills)      [ENGINEER        (DRAFT, AC1–AC6     (generated)
                                                 SIGN-OFF]        all PASS)
```

| Folder | Contents | Role |
|---|---|---|
| `1_raw_data/` | Official P45B datasheet v1.2, Molicel test report, Enepaq module datasheet (excluded from spec — third-party) | Source documents, never fed directly to model generation |
| `2_prompts/` | `spec_extraction_prompt.md`, `model_generation_prompt.md` | The harness artifacts: versioned, team-customizable |
| `3_spec/` | `spec.md` — engineer-signed 11.06.2026 | Single source of truth; the **only** input generation may see |
| `4_model/` | `molicel_48v_pack.slx`, `molicel_48v_pack_params.m` | The generated draft model + spec-traceable parameters |
| `5_docs/` | `molicel_48v_pack_architecture.md` | Generated architecture & block reference |

## Run it

```matlab
cd 4_model
molicel_48v_pack_params           % load spec-traceable parameters
open_system('molicel_48v_pack')   % open the model
sim('molicel_48v_pack');          % 18 A (1C) discharge, stops at 32.5 V UV cutoff (~3585 s)
```

## Key properties

- Every block parameter traceable to a `spec.md` table cell (see block Description fields)
- Identification data (datasheet + 0.2C curve) kept disjoint from validation data
  (high-rate curves, held back — spec §8)
- Model is a **DRAFT**: ASSUMED RC split and pending §8 independent validation are
  declared, not hidden (spec §9, architecture doc §7)
