## 5. Protection subset

**Modeled (Logic/Stateflow only):**
- **Cell Overvoltage (COV):** If ANY cell V_cell_i >= V_COV_Thresh, start delay timer. If condition holds for t_COV_Delay, assert `COV_Flag` = 1.
- **COV Recovery:** If `COV_Flag` == 1 AND ALL cells V_cell_i <= (V_COV_Thresh - V_COV_Hyst), clear `COV_Flag` = 0.
- **Cell Undervoltage (CUV):** Identical state machine logic using CUV thresholds and delays.

**Explicitly OUT OF SCOPE (per config):**
- Short Circuit in Discharge (SCD) and Overcurrent in Discharge/Charge (OCD/OCC).
- Temperature sensing (internal or external thermistors).
- Cell balancing (autonomous or host-controlled).
- I2C, SPI, or HDQ communication protocols.
- Coulomb counting and current ADCs.

## 6. Simulation scenario

- **Maneuver:** Continuous array of 14 cell voltages provided as input.
- **Profile:**
  - t = 0 to 1.0 s: All cells steady at 3.7 V.
  - t = 1.0 to 2.0 s: Cell #5 steps to 4.3 V (triggering condition).
  - t = 2.0 to 3.0 s: Cell #5 drops to 4.2 V (inside hysteresis band).
  - t = 3.0 to 4.0 s: Cell #5 drops to 4.1 V (full recovery).
- **Solver:** Fixed-step discrete, T_s = 1 ms.
- **Outputs:** `COV_Flag`, `CUV_Flag`, `Timer_Count_COV`.
